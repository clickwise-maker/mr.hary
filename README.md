# Mr. Harry — AI Digital Products

This repository stores customer-facing digital product guides, setup kits, supporting READMEs, and marketplace listing copy created with AI-assisted workflows.

## Product structure
Each product should have a numbered folder, with customer files in product-files/ and marketplace copy stored separately from the main guide.

## Quality workflow
1. Capture the complete generated source content.
2. Review technical accuracy, links, licensing, and safety caveats.
3. Commit the customer package and verify the committed files.
4. Create the downloadable PDF/ZIP package and test it before marketplace upload.
5. Upload to Payhip only after the download package is confirmed.
