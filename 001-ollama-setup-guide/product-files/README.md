# Ollama Setup Guide — Customer Package

This package contains a beginner-friendly guide to installing Ollama on Windows, macOS, and Linux; running local models; using the local API; connecting compatible apps; and troubleshooting common problems.

## Files
- ollama-setup-guide.md — main customer guide
- PAYHIP-LISTING.md — product title and storefront copy

## Getting started
1. Open the guide.
2. Use the official Ollama links in the guide to confirm current install instructions.
3. Choose a model based on your device's available RAM/VRAM.
4. Run the example commands and API requests only after Ollama is installed.

## Important
Hardware requirements vary by model, quantization, and context size. Local inference does not mean every connected application is offline; review the privacy and security checklist.
